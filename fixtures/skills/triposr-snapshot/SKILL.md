# TripoSR Snapshot

Metadata-only fixture pinned to the official VAST-AI-Research/TripoSR repository.

## Capabilities

TripoSR performs fast single-image 3D reconstruction and image-to-3d / image to mesh conversion.
Its documented inference path can also perform texture baking for reconstructed models.

## Runtime

The upstream implementation uses Python and PyTorch. GPU acceleration is optional.
