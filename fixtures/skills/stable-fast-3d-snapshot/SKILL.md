# Stable Fast 3D Snapshot

Metadata-only fixture pinned to the official Stability-AI/stable-fast-3d repository.

## Capabilities

Stable Fast 3D performs fast single-image 3D reconstruction and image-to-3d / image to mesh conversion.
It produces textured mesh assets with UV unwrapping, illumination removal, and material parameters.
The documented manual inference path provides GLB export and exports the reconstructed result as GLB.

## Runtime

The upstream implementation uses Python and PyTorch with CPU and optional GPU backends.
