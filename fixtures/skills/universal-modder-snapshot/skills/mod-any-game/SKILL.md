# Mod any game

## Safety boundary

- Authorized ownership is required.
- Testing stays in offline modes or user-controlled servers.
- Protection and ownership checks remain intact.
- Packages contain original mod code and assets, never game-owned files.
- Create a backup before modifying saves, profiles, or game folders.
- Get human confirmation before system or game-folder changes, deletion, or publishing.
