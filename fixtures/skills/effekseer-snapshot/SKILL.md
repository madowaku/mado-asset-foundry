# Effekseer Snapshot

Metadata-only fixture pinned to the official Effekseer repository.

## Role

Effekseer is a particle effect editing tool for games. It supports editing particle effects and effects can be played back in an application through runtimes and plugins.

## MAF capabilities

This fixture declares create particle effects, edit Effekseer effects, and Effekseer runtime playback.

The upstream master branch is a development branch, so this snapshot is evidence-only and is not an executable production adapter.
