# Effekseer AI Snapshot

Metadata-only fixture pinned to laodeng000/effekseer-ai.

## Role

Effekseer AI is a Python CLI and MCP server for creating and editing Effekseer effects with AI agents. It uses the official EffekseerCore.dll API.

## MAF capabilities

It can create Effekseer effects, edit .efkefc effect documents, import image assets into effect-local resources, export runtime .efk files, and provide an Effekseer MCP server for creating and editing Effekseer effects for MCP-compatible AI clients.

## Runtime

The verified upstream configuration requires Windows 10 or later, Python 3.11 or later, .NET 9 Runtime, the official Effekseer 1.80.6 Windows distribution, and EFFEKSEER_AI_BIN_DIR pointing to Tool/bin.
