# Effekseer For Godot 4 Snapshot

Metadata-only fixture pinned to the official EffekseerForGodot4 repository.

## Role

This is the Effekseer runtime plugin for Godot Engine 4.x.

## MAF capabilities

It provides Effekseer effects in Godot Engine 4.x and Godot VFX playback for runtime effect assets. It can play Effekseer effects inside a Godot project.

This fixture describes playback only. It does not claim Effekseer authoring or AI editing capabilities.
